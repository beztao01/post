## Requierimientos técnicos de Davinci 

Para ejecutar DaVinci Resolve con fluidez, tu equipo necesita cumplir con especificaciones técnicas exigentes de memoria y tarjeta gráfica, especialmente si planeas usar la herramienta de efectos visuales Fusion. Puedes descargar el instalador oficial directamente desde la página de Blackmagic Design DaVinci Resolve.


### Requisitos para Windows y Linux
- Sistema operativo: Windows 10 o 11 / CentOS 7.3 en adelante.
- Memoria RAM: Mínimo 16 GB (se recomiendan 32 GB si usas Fusion).
- Tarjeta gráfica (GPU): Discreta o integrada con al menos 2 GB a 4 GB de VRAM compatible con OpenCL 1.2 o CUDA.

### Requisitos para macOS
- Sistema operativo: macOS 12 (Monterey) o posterior.
- Memoria RAM: Mínimo 8 GB (se recomiendan 16 GB o más para Fusion).
- Gráfica: Compatible con Metal o chips integrados de Apple (M1/M2/M3 en adelante) con al menos 2 GB de VRAM equivalente.

### Almacenamiento y Recomendaciones
- Disco: Se requiere un disco de estado sólido (SSD) con espacio libre para instalar el software y almacenar la caché del proyecto de forma fluida.
